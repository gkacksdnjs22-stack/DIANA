DIANA PC 금융 문서 검토 · Windows x64 휴대용 실행기

1. ZIP 전체를 쓰기 가능한 로컬 폴더에 압축 해제합니다.
2. DIANA.exe를 실행합니다. EXE만 다른 곳에 옮기지 마세요.
3. 기존 PC 연결 설정이 있으면 실행과 동시에 자동 연결합니다.
   처음 사용하는 PC에서만 ‘연결 설정’에서 기존 worker.json,
   AGENT_TOKEN이 있는 .env, 일반 DIANA 파일 폴더를 한 번 선택합니다.
4. 설정을 저장하면 바로 연결하고 PC 검토 화면이 기본 브라우저에 열립니다.
5. ‘연결 종료’ 또는 창의 X는 진행 중 처리를 기다린 뒤 worker를 종료합니다.
   브라우저 탭만 닫으면 worker는 계속 실행합니다.

자동 연결 (0.2.1)

연결에 성공하면 설정 파일 경로와 서버 주소만 이 PC에 기억합니다.
연결 키 내용은 공통 설정에 복사하지 않습니다.
공통 설정: %LOCALAPPDATA%\DIANA\financial-desktop\desktop.json
새 버전을 다른 폴더에 압축 해제해도 이 설정을 재사용합니다.
실행 폴더의 .local\desktop.json이 있으면 그 설정을 먼저 사용합니다.
--settings로 지정한 별도 테스트 설정은 공통 설정을 바꾸지 않습니다.

문서와 작업 등록 (0.2.0)

1. PC 검토 화면 왼쪽의 ‘문서 · 작업 등록’을 누릅니다.
2. 검토할 문서·근거 자료·검토 지침을 각각 선택해 PC에 등록합니다.
   TXT·MD·JSON(UTF-8, 256KB 이하)을 지원하며, 지침은 기존 rules 형식의
   JSON입니다. 지침의 id/version은 문서 코드/버전과 맞아야 하고,
   source_ids는 선택한 근거 자료의 문서 코드와 맞춰 주세요.
3. 작업 이름, 검토할 문서, 근거 자료, 지침, 보완 항목과 형식을 선택합니다.
4. 작업 등록 후 ‘모바일 작업 목록 반영 완료’를 확인합니다.
   모바일 금융 문서 모드에서 새로고침하면 새 작업을 선택할 수 있습니다.

등록 파일은 PC 전용 사본입니다. 원본을 수정해도 등록본은 자동으로
바뀌지 않습니다. 변경된 자료는 새 문서 코드로 등록해 주세요.
기존 문서/작업 수정·삭제 대신 새 등록을 추가하는 방식입니다.
검토·승인·저장 중에는 새 등록을 막아 기존 수정안을 보존합니다.
모바일에는 작업 이름·동작·형식만 전달하며 파일명·문서 코드·경로와
본문은 전달하지 않습니다. 연결이 끊기면 PC 등록 상태로 대기합니다.

이 실행기는 기존 Render 서버와 금융 요청·상태 API를 사용합니다.
문서·근거·수정안·결과 파일·최종 승인은 PC에 유지합니다.
다른 PC에는 그 PC에서 검토한 작업·문서·권한 설정과 연결 키가 필요합니다.
배포 ZIP에는 사용자 설정·연결 키·원문·결과 파일·학습 모델이 없습니다.

Node와 Python 런타임을 함께 제공합니다. 기존 core.json의 python 경로는
자동 변경하지 않습니다. 새 PC용 설정을 만들 때는 이 폴더의
runtime\python\python.exe 절대 경로를 등록할 수 있습니다.
현재 가상 작업 생성 도구: app\scripts\init-financial-mobile-demo.mjs
이 도구는 개발자용이며 사용자 문서를 자동으로 등록하지 않습니다.

동일 Windows 로그인에서는 실행기 창 하나만 사용합니다.
기존 CMD 금융 worker가 실행 중이면 기존 창에서 exit로 종료한 뒤 연결합니다.
학습 프로그램이나 일반 DIANA 에이전트에는 영향을 주지 않습니다.
연결이 끊기면 자동 재시도하며, 원문과 결과는 PC에 남습니다.

Windows 10/11 x64 및 .NET Framework 4.8이 필요합니다.
현재 EXE는 코드 서명 전 개발 배포본입니다.
로컬 실행 검증은 이 PC에서 수행하며 다른 PC 실기기 검증은 별도입니다.
라이선스·구성 파일 해시는 LICENSES 및 manifest.json에서 확인할 수 있습니다.
