ANDROID APP

DIANA for Android

버전 0.3.9 / Android 8.0 이상

APK

파일을 주고받고, PC에 작업을 요청하세요.
처리 상태는 휴대폰에서 확인할 수 있어요.

Android APK 받기 4.2 MB
  1. 다운로드한 DIANA-0.3.9.apk를 열어 설치하세요.
  2. 앱의 연결 안내에 따라 내 PC와 연결하세요.

기기 설정에 따라 설치 권한 확인이 필요할 수 있어요.

Android 버전 안내 +
  • ‘PC에 요청하기’로 파일·문서 요청 통합
  • 대화 입력창과 기기 내부 초안 보관
  • 입력 중 화면 갱신·키보드 가림 방지 개선

현재 대화 초안은 전송·실행되지 않습니다. 로컬 AI 학습·검증 후 연결할 예정입니다.

WINDOWS WORKSPACE

DIANA for Windows

버전 0.3.6 / Windows 10·11 x64

ZIP

문서와 작업을 등록하고, 내 PC에서 검토하세요.
기존 연결 설정은 새 버전에서도 재사용합니다.

Windows ZIP 받기 59.4 MB
  1. ZIP 전체를 압축 해제하세요.
  2. DIANA-PC 폴더의 DIANA.exe를 실행하세요.

EXE만 따로 옮기지 마세요. .NET Framework 4.8이 필요하며, 처음 사용하는 PC는 연결 설정이 필요합니다.

Windows 버전 안내 +
  • PC 문서·작업 등록과 자동 연결
  • 로컬 요청 기록·검토·교정 자료 보관
  • Node·Python 실행 환경 포함

코드 서명 전 개발용 ZIP 배포본입니다. 실험용 AI 미리보기는 별도 수동 기능이며, 모바일 대화 요청과 연결되지 않습니다.

두 버전 모두 개발 중인 테스트 버전입니다. 문서 처리를 위해서는 PC가 켜져 있고 DIANA에 연결돼 있어야 합니다.

GOOD TO KNOW

시작하기 전에.

PC를 꺼둬도 문서 작업이 진행되나요?+

문서 작업은 PC에서 실행됩니다. 요청을 처리하려면 PC가 켜져 있고 DIANA가 연결돼 있어야 합니다.

지금 AI와 대화해서 요청할 수 있나요?+

현재 0.3.9의 대화 입력창은 초안 보관 단계입니다. 로컬 AI의 학습과 성능 검증을 마친 뒤 연결할 예정입니다. 지금은 ‘PC에 요청하기’의 기존 작업 도구를 이용하세요.

기존 웹 작업 화면은 어디에 있나요?+

기존 연결·파일 전송 기능은 웹 작업 화면에서 계속 사용할 수 있습니다. 사용자 연결 코드가 필요합니다.
