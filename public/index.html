내 PC 연결

연결 전

초기 버전은 PC에 설정한 사용자 연결 코드로 접속합니다.

휴대폰 파일을 PC로 보내기

파일 전송

이 기기의 파일을 선택해 PC의 휴대폰 수신 폴더에 저장합니다. PC가 꺼져 있으면 연결될 때까지 기다립니다.

한 번에 파일 1개, 최대 10MB까지 보낼 수 있습니다. 전송할 파일은 서버에 최대 24시간 임시 보관됩니다.

선택한 파일이 없습니다.

보고서·발표자료 예약 생성

원문 기반 작성·검토

원문의 사실과 수치를 유지하면서 새 보고서와 발표자료를 작성합니다. 기존 파일의 내용을 직접 바꾸려면 아래 ‘파일 수정·전달’을 이용하세요.

PC 에이전트가 지정된 문서 폴더의 이름과 해시를 동기화합니다. 파일 내용 전체는 서버에 올리지 않습니다.

갤럭시 동기화 시간을 확보하려면 완료 기한을 작업 시작보다 최소 30분 뒤로 정하세요. API 키가 없거나 근거 검토가 끝나지 않으면 미완성으로 알립니다. Android 절전·네트워크 상태는 저장 시간을 늦출 수 있습니다.

갤럭시 자동 저장 연결

Android 앱에 서버 HTTPS 주소와 코드를 입력해 한 번 연결합니다. USB 파일전송 모드만으로는 휴대폰 앱이 PC의 127.0.0.1 주소에 접속할 수 없습니다.

파일 수정·전달

기존 파일을 찾거나 텍스트·코드 수정본을 만들어 휴대폰이나 메일로 받습니다.

UTF-8 텍스트·코드 파일은 원본을 보존하고 수정본을 따로 만듭니다. JSON은 저장 전 문법을 확인합니다. HWP·HWPX·엑셀·PPTX·PDF·DOCX는 읽고 보고서 작성에 사용할 수 있습니다.

처음에는 가상 문서와 연습 메일로 동작합니다. 실제 발송 연결 상태는 PC 설정에 따릅니다.
