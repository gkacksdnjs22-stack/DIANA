ANDROID APP

DIANA for Android

0.8.0-dev-paired3 / Android 8.0 이상

APK

파일을 주고받고, PC에 작업을 요청하세요.
처리 상태는 휴대폰에서 확인할 수 있어요.

Android APK 받기 4.4 MB
  1. 다운로드한 DIANA-Android-0.8.0-dev-paired3.apk를 열어 설치하세요.
  2. PC에서 발급한 6자리 코드를 휴대폰 앱에 입력하세요.

기존 Android 0.3.9와 별도로 설치되는 개발판입니다. 이전 paired 개발판은 업데이트 설치할 수 있어요.

Android 버전 안내 +
  • 6자리 코드로 PC 연결
  • 문서 요청과 저장 파일을 앱에서 확인
  • 연결한 PC에서 승인한 결과를 휴대폰에 저장

개발용 APK입니다. Android 설정에 따라 설치 권한 확인이 필요할 수 있습니다.

WINDOWS WORKSPACE

DIANA for Windows

0.8.0-dev-paired3 / Windows 10·11 x64

ZIP

허용한 폴더의 문서를 찾고, 내 PC에서 결과를 확인해 저장하세요.

Windows ZIP 받기 77.7 MB
  1. ZIP 전체를 압축 해제하세요.
  2. DIANA-PC 폴더의 DIANA.exe를 실행하세요.

ZIP 전체가 필요합니다. .NET Framework 4.8을 사용하며, 첫 실행에서 PC를 등록하세요.

Windows 버전 안내 +
  • 작업·파일·설정 화면과 보고서·발표자료 디자인 개선
  • 허용 폴더 검색, 보고서·발표자료 작성과 형식 변환
  • Node·Python 실행 환경 포함

코드 서명 전 개발용 ZIP입니다. 문서 미리보기와 저장 승인은 PC에서 확인하세요.

두 버전 모두 개발 중인 테스트 버전입니다. 문서 처리를 위해서는 PC가 켜져 있고 DIANA에 연결돼 있어야 합니다.

GOOD TO KNOW

시작하기 전에.

PC를 꺼둬도 문서 작업이 진행되나요?+

문서 작업은 PC에서 실행됩니다. 요청을 처리하려면 PC가 켜져 있고 DIANA가 연결돼 있어야 합니다.

지금 AI와 대화해서 요청할 수 있나요?+

문서 요약, 보고서 작성, 파일 변환 등 지원하는 작업을 요청할 수 있습니다. 자료가 모호하면 PC에서 확인하고 결과를 승인하세요.

기존 웹 작업 화면은 어디에 있나요?+

기존 연결·파일 전송 기능은 웹 작업 화면에서 계속 사용할 수 있습니다. 사용자 연결 코드가 필요합니다.
