GOOD TO KNOW

시작하기 전에.

PC를 꺼둬도 문서 작업이 진행되나요?+

문서 작업은 PC에서 실행됩니다. 요청을 처리하려면 PC가 켜져 있고 DIANA가 연결돼 있어야 합니다.

지금 AI와 대화해서 요청할 수 있나요?+

현재 0.3.9의 대화 입력창은 초안 보관 단계입니다. 로컬 AI의 학습과 성능 검증을 마친 뒤 연결할 예정입니다. 지금은 ‘PC에 요청하기’의 기존 작업 도구를 이용하세요.

기존 웹 작업 화면은 어디에 있나요?+

기존 연결·파일 전송 기능은 웹 작업 화면에서 계속 사용할 수 있습니다. 사용자 연결 코드가 필요합니다.
