갤럭시 자동 저장 연결

Android 앱에 서버 HTTPS 주소와 코드를 입력해 한 번 연결합니다. USB 파일전송 모드만으로는 휴대폰 앱이 PC의 127.0.0.1 주소에 접속할 수 없습니다.

파일 하나 찾기 또는 메일로 받기
