# 통합 요청 화면과 대화 초안 · Android 0.3.9

모바일 메뉴의 `PC에 요청하기`에서 일반 파일 찾기·수정 요청, 휴대폰 파일 보내기, PC에 등록한 문서 검토·보완·변환을 이용한다. 별도 금융 메뉴는 제거했다. 문서의 주제와 지침에 따라 기존 처리기를 사용하며, 금융 문서의 원문·근거·Diff·결과 파일·최종 승인은 계속 PC에 둔다.

## 대화 입력창

상단 `DIANA 대화`에 원하는 문장을 작성하고 `대화 초안 보관`을 누르면 휴대폰 내부에 보관한다. 최대 2,000자이며 한국어·줄바꿈·이모지를 보존한다. 화면 이동과 앱 재생성 시 작성 내용도 복원한다. 초안은 서버 주소와 휴대폰 연결 ID의 해시로 구분하며 연결 토큰을 저장하지 않는다.

초안 말풍선과 보관 안내는 기기 내부 저장을 뜻한다. 메시지 전송·PC 접수·AI 응답·검토·업무 저장을 뜻하지 않는다. 이 버전의 `AI 연결 후 요청 가능` 버튼은 비활성이다. 사용자는 학습과 성능 확인 후 AI를 연결하기로 결정했으므로 자연어 중계 API, 모델 실행과 활성 모델 교체를 추가하지 않았다.

지금 수행할 작업은 바로 아래 기존 작업 도구를 이용한다. 파일 검색·수정 요청은 기존 일반 요청 경로, 등록 문서 검토·보완·변환은 기존 문서 작업 경로를 사용한다. 두 경로의 권한·확인·전달 범위는 화면 통합으로 바뀌지 않는다.

## 화면 갱신

요청 화면에서 문서 상태는 기존 행만 갱신한다. 일반 파일 동기화의 상태 변경 때문에 요청 화면을 새로 만들지 않으며, 대화 입력창도 키보드 가림 방지와 입력 중 자동 재생성 지연 대상에 포함한다. 과거 금융 화면 복원·이동은 통합 요청 화면으로 연결한다.

## 검증과 후속 작업

단위 검사에는 초안 길이·문자 검증과 연결별 분리가 포함된다. Android 계측 검사에는 통합 메뉴 열기, 반복 상태 갱신 중 화면 유지, 초안 보관·앱 재생성 복원과 기존 작업 요청을 생성하지 않는 동작이 포함된다. 계측 APK 빌드와 기기에서 실제 실행한 결과는 구분해서 기록한다.

다음 단계는 학습 완료 모델의 성능과 지원 동작을 확인한 뒤 요청 전달 계약, 모호한 요청 확인, 실제 PC 해석·선택 확인을 연결하는 것이다. 현재 초안은 나중에도 자동으로 전송하거나 실행하지 않는다.
