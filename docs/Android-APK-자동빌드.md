# Android Studio 없이 DIANA APK 받기

DIANA의 Android 소스가 변경되면 GitHub Actions가 **개발용 APK**를 빌드하고 14일간 다운로드할 수 있는 작업 결과를 제공합니다.

## APK 다운로드 순서

1. GitHub에서 DIANA 저장소를 엽니다.
2. **Actions** 탭에서 **DIANA Android APK**를 선택합니다.
3. PR #1에서 실행된 최신 작업을 엽니다. 초록색 체크(**Success**)가 표시돼야 합니다.
4. 맨 아래 **Artifacts**에서 **DIANA-debug-apk**를 클릭해 ZIP을 받습니다.
5. ZIP을 압축 해제하면 `app-debug.apk`가 있습니다. 이 파일을 갤럭시로 전송하고 설치합니다.

GitHub에서 Actions 실행이 보이지 않으면 저장소의 Actions 사용이 허용되어 있는지 확인합니다. 기본 브랜치에 이 워크플로가 반영되면 **Run workflow** 버튼으로 수동 재빌드할 수도 있습니다.

## 테스트 전 주의

- APK는 개발용 **debug 서명**입니다. GitHub의 새 빌드와 기존 `앱-설치/DIANA-debug.apk`의 서명 키가 서로 다를 수 있습니다. 설치 시 서명 충돌이 나오면 기존 앱을 제거하고 설치해야 할 수 있습니다. **앱 제거 시 DIANA 연결 정보와 앱 내부 저장 파일이 삭제될 수 있으므로 먼저 별도 폴더에 파일을 복사하고, 재연결용 6자리 코드를 받을 준비를 하세요.**
- Android 앱을 새로 설치하는 것만으로 서버가 업데이트되는 것은 아닙니다. PR #1의 서버 코드까지 Render에 배포되어야 **갤럭시 저장 확인**까지 정상 처리됩니다.
- 처음에는 앱의 **지금 결과 확인** 버튼으로 단일 문서 다운로드·SHA-256 검증·**내 저장 파일** 열기를 확인하세요. 다음으로 자동 수신을 켜고 앱을 닫은 상태의 동기화를 시험합니다. Android 절전 정책에 따라 15분보다 오래 걸릴 수 있습니다.
- 이 작업은 APK **빌드/다운로드를 자동화**하며, 갤럭시 실기기에서 자동 저장 성공까지 보증하는 것은 아닙니다.
